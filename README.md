# 🎮 IGPM – Indie Game Project Manager

**One studio. One team. One workspace.**

IGPM is an internal web-based management tool developed exclusively for **Lumaru Studios**.

Its purpose is to centralize studio organization, project management, and team collaboration in one place.

## 🚀 Features

- **Dashboard** – Overview of studio activities and projects.
- **Task Management** – Create, assign, and track tasks.
- **Project Management** – Organize projects and milestones.
- **Team Management** – Manage members, roles, and responsibilities.
- **Wiki** – Store and organize internal knowledge.
- **Documentation** – Manage technical and project documentation.
- **Bug Tracker** – Report and track development issues.

## 🎯 Purpose

IGPM is designed to improve internal workflows, simplify collaboration, and keep all important studio information organized.
